# XXD Panel 079 · 日本語読解ガイド

各写真を独立した3:4ポスターにし、上半分は現実の写真、下半分は未完成感のあるペン淡彩へ変換します。下部には、最も識別力のある主体、輪郭、姿勢、空間、物語関係だけを残します。

長い直線透視、折れ線、幾何学軸、平面化で理性的な骨格を作り、人物・植物・動物・雲・水などの有機曲線、探り線、断線、微かなずれ、未完の縁で手描きの即興性を加えます。

色は元写真から選んだ少数の識別色だけを透明水彩で軽く置きます。はみ出し、水跡、粒子、塗りむらを許容し、広い自然な紙白を残して、墨線・淡彩・余白の階層を作ります。複雑な背景は削除し、紙白に空気、距離、光、間を担わせます。

文字は少量で意味のあるものに限り、細く抑制された編集書体を使います。透視線、幾何学軸、主体の縁、余白に沿って配置し、一般的な「見出し＋本文」にしません。建築旅行スケッチブック、独立視覚誌、現場観察ノートのように仕上げ、写実精描、背景の塗り込み、乱雑な落書き、整いすぎた製図、太い黒輪郭、写真輪郭フィルター、漫画、3D、商業テンプレートを避けます。
