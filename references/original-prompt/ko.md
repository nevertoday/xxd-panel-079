# XXD Panel 079 · 한국어 읽기 가이드

각 사진을 독립된 3:4 포스터로 만들고, 위쪽 절반은 현실 사진으로 보존하며 아래쪽 절반은 미완성 감각의 펜 앤 워시 스케치로 전환합니다. 아래에는 가장 식별력 있는 피사체, 윤곽, 자세, 공간, 서사 관계만 남깁니다.

긴 직선 원근선, 꺾인 윤곽, 기하 축과 평면 단순화로 이성적 골격을 세우고, 인물·식물·동물·구름·물의 유기 곡선과 탐색선, 끊긴 선, 약간의 어긋남, 미완성 가장자리로 손의 즉흥성을 더합니다.

색은 원본 사진에서 고른 소수의 식별색만 투명 수채로 가볍게 찍습니다. 약간의 번짐, 물자국, 입자, 고르지 않은 덮임을 허용하고 넓은 자연스러운 종이 흰색을 남겨 잉크선·담채·여백의 위계를 만듭니다. 복잡한 배경은 제거하고 여백이 공기, 거리, 빛과 멈춤을 맡게 합니다.

글자는 적고 의미 있어야 하며 가늘고 절제된 편집 서체를 사용합니다. 원근선, 기하 축, 피사체 가장자리, 넓은 여백을 따라 배치하고 일반적인 ‘제목+본문’ 메뉴형 구성을 피합니다. 건축 여행 스케치북, 독립 비주얼 저널, 현장 관찰 수첩처럼 완성하며 정밀 사실화, 가득 찬 배경, 혼란스러운 낙서, 지나치게 반듯한 기술 도면, 굵은 검은 윤곽, 사진 외곽선 필터, 만화, 3D, 상업 템플릿을 피합니다.
